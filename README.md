# Тест на проверку получения заказа по его номеру приложения "Яндекс Самокат".
- Для запуска тестов должны быть установлены пакеты pytest и requests.
- Запуск всех тестов выполняется командой pytest.
- При использовании программы нужно заменить значение параметра "URL_YASAMOKAT" в файле "configuration.py".
- Сам тест реализован в файле "get_order_by_track_test.py", проверяется что при отправке запроса возвращается статус-код "200".
-Текствый файл "Задание1и2_postgreSQL.txt" - получение среза данных в базе данных из таблиц "Couriers" и "Orders", к проверке отправки запроса этот файл не относится.
